# Agent overview

<AgentAvailability />

Point an AI assistant at axonia. It acts as the connected member, limited to the
granted permissions, over the Model Context Protocol (MCP).

## Bounded delegation

A connected agent can only ever reach the tools axonia builds for agents, never
every door the account has. Each key carries only the permissions chosen for it,
and can be revoked at any time.
